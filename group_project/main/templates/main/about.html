About ASD Insight

Explainable AI-Based Prediction Framework for Autism Spectrum Disorder

What is Autism Spectrum Disorder (ASD)?

Autism Spectrum Disorder (ASD) is a neurodevelopmental condition that affects communication, social interaction, behaviour and learning. Early identification helps individuals receive timely intervention and appropriate support.

About This System

ASD Insight is an intelligent screening system developed using Django and Machine Learning. The system analyses responses from the AQ-10 questionnaire and predicts whether characteristics associated with Autism Spectrum Disorder are present.

Explainable Artificial Intelligence (XAI)

Unlike traditional AI systems, this framework explains why a prediction was made. SHAP (SHapley Additive exPlanations) identifies the most influential features, allowing users and healthcare professionals to understand the model's decision.

Technologies Used

  • Python
  • Django Framework
  • Random Forest Machine Learning
  • SHAP Explainable AI
  • Bootstrap 5
  • HTML, CSS and JavaScript
